EASYQUERY FOR SPAs

A query builder for your React, Angular, Vue or Blazor app

EasyQuery.JS gives your single-page application a visual query builder, a result grid and charts. Behind it: the EasyQuery ASP.NET Core backend, or EasyQuery Server on your own servers for any other backend.

WHAT YOU GET

YOUR FRAMEWORK

The widgets work in React, Angular, Vue, Blazor and plain web components, as well as in classic MVC or Razor pages. There are ready-to-run samples for each.

YOUR BACKEND

With ASP.NET Core, the EasyQuery backend does all the server work in one MapEasyQuery call. With any other backend, EasyQuery Server generates the SQL for you.

WRITTEN IN TYPESCRIPT

EasyQuery.JS is written in TypeScript and published on npm (@easyquery/core, @easyquery/ui), so you get type checking and IntelliSense even in plain JavaScript.

USER-FRIENDLY UI

All the complexity of SQL is hidden: users add columns and conditions in plain language and see the result at once.

HOW IT WORKS

With the EasyQuery backend

for ASP.NET Core, the usual path

With EasyQuery Server

for any other backend: Java, Node.js, PHP, Python…
1
EasyQuery.JS (embedded in your page or component) requests the data model from your server-side application.

The data model defines which entities and attributes users can operate with when they build their queries, and how they relate to each other.

The ASP.NET Core backend builds the data model at run time from your DbContext or database. With EasyQuery Server, you create the data model with a special utility.

2

The user builds a query: adds or changes columns and conditions in the EasyQuery.JS UI.

EasyQuery.JS sends the JSON representation of the query to your application.

With EasyQuery Server, your application passes the query JSON on to the Server.

3

The query JSON becomes SQL.

With the EasyQuery backend, the EasyQuery code in your application does it.

With EasyQuery Server, the Server generates the SQL and sends it back to your application.

Your application runs the SQL against your database, under your own access rules.

4

The application gets the result and sends it to EasyQuery.JS, which shows it in the grid or as a chart.

HOW TO START

A FEW LINES IN YOUR COMPONENT

From the React sample: the view, the backend endpoint, and that's it. The same with either backend below.

import { AdvancedSearchView } from '@easyquery/ui';
import '@easyquery/enterprise';

const view = new AdvancedSearchView();
view.getContext()
    .useEndpoint('/api/easyquery')
    .useEnterprise(() => view.init({
        loadModelOnStart: true,
        result: { showChart: true }
    }));

ASP.NET CORE BACKEND

Setting up the backend is easy: a few lines in Program.cs add the EasyQuery endpoint and connect it to your database through your DbContext. The data model comes from the same DbContext, so there is nothing else to describe.

builder.Services.AddEasyQuery()
    .UseSqlManager();
...
app.MapEasyQuery(options => {
    options.Endpoint = "/api/easyquery";
    options.UseDbContext<AppDbContext>();
});

To see it all working together, start from the sample for your frontend. Each one is a complete ASP.NET Core 10 solution, frontend and backend, that runs as soon as you open it:

  • React — advanced search
  • Angular — advanced search, ad-hoc reporting
  • Vue — Vue 3 and Vue 2
  • Blazor — Blazor Server and WebAssembly
  • Web components (Stencil) — advanced search

ANY OTHER BACKEND: EASYQUERY SERVER

EasyQuery Server (EQS) is a small web service that does the server-side work EasyQuery.JS needs: it holds the data model and generates the SQL. Your application only forwards the frontend's requests to EQS and runs the SQL it gets back.

EasyQuery Server comes with the EasyQuery.JS Company license, to install on your own servers. It runs on .NET, so on Linux, Windows or macOS, and in Docker.

There is also a public EQS instance on SqlQueryBuilder.com. It is free, but has some limitations.

Sample projects for Node.js and PHP are available on GitHub. If you need a sample for your platform of choice, please contact us.
